Vite 项目配置 @ 路径别名 ​

1. 作用 ​

在项目中使用 @ 代替 src 目录，避免出现过长的相对路径：

ts
// 不推荐
import Button from '../../../components/Button'

// 推荐
import Button from '@/components/Button'
1
2
3
4
5

这里的 @ 通常约定指向项目的 src 目录。

2. Vite 8 推荐配置 ​

Vite 8 已支持直接读取 TypeScript 的 paths 配置。推荐只在 tsconfig 中声明别名，然后在 Vite 中开启 tsconfigPaths。

tsconfig.json ​

json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}

json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}

import { defineConfig } from 'vite'

  resolve: {
    tsconfigPaths: true

3. 是否需要 baseUrl ​

现在通常不需要添加：

ts
"baseUrl": "."
1

TypeScript 从 4.1 开始支持不依赖 baseUrl 的 paths 配置。paths 没有设置 baseUrl 时，会相对于当前 tsconfig 文件解析。

因此推荐使用：

ts
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
1
2

6
7

而不是：

ts
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  }
}

4. 旧项目的手动配置方式 ​

如果项目没有启用 Vite 8 的 resolve.tsconfigPaths，可以在 vite.config.ts 中手动配置：

ts
import { defineConfig } from 'vite'
import { fileURLToPath, URL } from 'node:url'

export default defineConfig({
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  }
})

  • 项目没有启用 resolve.tsconfigPaths；
  • 需要对别名做更复杂的自定义；
  • 项目中存在多个特殊别名。

5. 常见错误 ​

错误一：只配置 tsconfig ​

json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
1
2
3
4
5
6
7

TypeScript 和编辑器可能能识别，但 Vite 没有开启 tsconfigPaths 时，运行或构建可能报错。

Vite 8 项目需要：

json
resolve: {
  tsconfigPaths: true
}
1
2
3

错误二：只配置 Vite ​

只在 vite.config.ts 中写：

json
resolve: {
  alias: {
    '@': '/src'
  }
}
1
2
3
4
5

项目运行可能正常，但 TypeScript、ESLint 或编辑器可能无法识别 @。

因此最好同时配置 tsconfig。

错误三：路径多写了一层 src ​

如果 @ 已经指向 src，就不要再写：

ts
import Button from '@/src/components/Button'
1

正确写法是：

ts
import Button from '@/components/Button'
1

错误四：修改配置后没有重启 ​

修改 vite.config.ts 或 tsconfig.json 后，如果编辑器仍然报错，可以：

  1. 重启 Vite 开发服务器；
  2. 在 VS Code 中执行 TypeScript: Restart TS Server；
  3. 重新打开项目。

6. 多个别名的写法 ​

可以在 paths 中配置多个别名：

json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"],
      "@components/*": ["./src/components/*"],
      "@utils/*": ["./src/utils/*"],
      "@pages/*": ["./src/pages/*"]
    }
  }
}

不过普通项目通常只保留一个 @ 别名即可，避免别名过多导致路径规则难以维护。

7. 最终记忆模板 ​

新建或升级 Vite 8 项目时，直接使用下面这套配置：

tsconfig.json 或 tsconfig.app.json：

json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}

vite.config.ts：

记忆口诀：
